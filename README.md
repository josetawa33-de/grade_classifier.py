# Week 4 Assignment: Grades, Eligibility & Smart Decisions

This repository contains three Python programs:

- **grade_classifier.py** — Classifies scores into grades A–F with validation.  
- **eligibility_checker.py** — Determines coding club eligibility using age and parental consent.  
- **atm_menu.py** — Simulates an ATM with PIN check and withdrawal logic.

### Reflection
Using `elif` is better than several separate `if` statements when conditions are mutually exclusive. It ensures only one branch executes, avoids redundant checks, and makes the code easier to read and maintain.
